Daily hands-on practice notebooks from the CampusX Data Science Mentorship Program (DSMP), building core data analysis and visualization skills with NumPy, Pandas, Matplotlib, and Seaborn — one session at a time. 

## About

This repository tracks my session-wise practice while working through the DSMP curriculum. Each notebook is completed right after learning the corresponding concept, with the datasets used kept alongside the relevant session where applicable.

## Tech Stack

- **Language:** Python
- **Libraries:** NumPy, Pandas, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook

## What's Covered

**NumPy (Sessions 13–15)**
- Array creation and manipulation
- Indexing, slicing, and broadcasting
- Vectorized operations and mathematical functions

**Pandas (Sessions 16–22)**
- Series and DataFrame fundamentals
- Data cleaning and preprocessing
- Filtering, grouping, and aggregation
- Merging and joining datasets
- Exploratory data analysis

**Matplotlib (Sessions 23–24)**
- Plot types: line, bar, scatter, histogram
- Titles, labels, legends, and styling
- Subplots and figure customization

**Seaborn (Sessions 25–26)**
- Statistical plotting (distribution, relational, categorical)
- Built-in themes and color palettes
- Working with Seaborn's built-in datasets

## Running Locally

```bash

cd numpy-pandas-matplotlib-seaborn
```
